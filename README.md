# Проектная работа "Веб-ларек"

Стек: HTML, SCSS, TS, Webpack

Структура проекта:
- src/ — исходные файлы проекта
- src/components/ — папка с JS компонентами
- src/components/base/ — папка с базовым кодом

Важные файлы:
- src/pages/index.html — HTML-файл главной страницы
- src/types/index.ts — файл с типами
- src/index.ts — точка входа приложения
- src/scss/styles.scss — корневой файл стилей
- src/utils/constants.ts — файл с константами
- src/utils/utils.ts — файл с утилитами

## Установка и запуск
Для установки и запуска проекта необходимо выполнить команды

```
npm install
```

или

```

```

# Документация проекта

## Описание

Данный проект представляет собой интернет-магазин с товарами для веб-разработчиков — Web-ларёк. В нём можно посмотреть каталог товаров, добавить товары в корзину и сделать заказ. 

Проект выполнен на основе паттерна MVP (Model-View-Presenter) и включает в себя Модели (классы модели данных), Представления (классы компонентов представления) и Презентер, реализованный в файле index.ts, отвечающий за бизнес-логику.

## Типы данных

### `CategoryType`
Тип для определения категорий товара:
- 'другое'
- 'софт-скил'
- 'дополнительное'
- 'кнопка'
- 'хард-скил'

### `PaymentType`
Тип для определения способов оплаты:
- 'card'
- 'cash'
- null

### `FormErrors`
Тип для хранения ошибок валидации форм. Использует частичную запись (Partial) для указания возможных полей, содержащих ошибки.

### `IProduct`
Интерфейс, описывающий товар:
- category: CategoryType — категория товара.
- title: string — наименование товара.
- image: string — URL-адрес изображения товара.
- description: string — описание товара.
- price: number | null — стоимость товара (может быть числом или undefined).
- selected: boolean — статус выбора товара (выбран/не выбран).
- id: string — id товара.

### `ApiResponse`
Интерфейс, описывающий ответ API:
- items: IProduct[] — массив товаров.

### `IUserFormData`
Интерфейс, описывающий данные формы пользователя:
- payment: PaymentType — способ оплаты.
- total: number — сумма заказа.
- phone: string — контактный номер телефона пользователя.
- address: string — адрес пользователя.
- email: string — электронная почта пользователя.

### `IAppState`
Интерфейс, описывающий состояние приложения.
- basket: IProduct[] — корзина с товарами.
- store: IProduct[] — массив карточек товара.
- order: IOrder — информация о заказе при покупке товара.
- formErrors: FormErrors — ошибки при валидации форм.

## Методы

### `addToBasket(value: IProduct): void`
Добавляет товар в корзину.

### `deleteFromBasket(id: string): void`
Удаляет товар из корзины по его идентификатору.

### `clearBasket(): void`
Очищает корзину.

### `getBasketAmount(): number`
Возвращает количество товаров в корзине.

### `getTotalBasketPrice(): number`
Возвращает общую стоимость всех товаров в корзине.

### `setItems(): void`
Добавляет ID товаров в корзине в поле items для заказа.

### `setOrderField(field: keyof IUserFormData, value: string): void`
Заполняет поля email, phoneNumber, address, paymentMethod в заказе.

### `validateContacts(): boolean`
Валидация полей контактов.

### `validateOrder(): boolean`
Валидация формы заказа.

### `refreshOrder(): boolean`
Очищает информацию о заказе после завершения покупки.

### `setStore(items: IProduct[]): void`
Преобразует данные, полученные с сервера, в формат, используемый в приложении.

### `resetSelected(): void`
Сбрасывает поля selected у всех товаров после завершения покупки.

## Базовые классы
### 1. `Api`
Класс `Api` предназначен для упрощения взаимодействия с `RESTful API`. Он предоставляет методы для выполнения `HTTP-запросов`, таких как `GET` и `POST`, с автоматической обработкой ответов и ошибок.

### Свойства
- `baseUrl: string` — базовый URL для API, который передается в конструктор класса. Он используется для формирования полного URL для запросов.
- `options: RequestInit` — включает заголовки по умолчанию, такие как Content-Type, устанавливаемый на application/json.
  
### Методы
- `protected handleResponse(response: Response): Promise<object>` — возвращае промис, который разрешается в JSON-объект, если ответ успешный (статус 2xx). В противном случае он отклоняется с ошибкой, полученной из ответа или статусным текстом.
- `get` — возвращает промис, который разрешается в ответ API в формате JSON.
- `post` — промис, который разрешается в ответ API в формате JSON.

### 2. `Element`
Класс `Element<T>` является абстрактным базовым компонентом, который предоставляет инструменты для работы с DOM в дочерних компонентах. Он принимает в конструкторе HTML-элемент, который будет служить контейнером для содержимого.

### Методы для работы с DOM:
- `toggleClass` — переключает указанный класс у элемента.
- `setText` — устанавливает текстовое содержимое элемента.
- `setDisabled` — устанавливает или убирает атрибут disabled у элемента.
- `setHidden` — скрывает элемент, устанавливая стиль display: none.
- `setVisible` — показывает элемент, удаляя стиль display.
- `setImage` — устанавливает изображение и альтернативный текст для элемента <img>.

### Метод `render`
Метод `render(data?: Partial<T>): HTMLElement` — обновляет свойства текущего экземпляра на основе переданных данных и возвращает корневой DOM-элемент.

### 3. `Model`
Класс `Model` является абстрактным и представляет собой базовую модель.

## Классы модели данных
### 1. `Product`
Класс представляет собой модель товара, наследует функциональность от класса `Model`.

### Свойства 
- `category: CategoryType` — категория товара.
- `title: string` — наименование товара.
- `image: string` — URL-адрес изображения товара.
- `description: string` — описание товара.
- `price: number | null` — стоимость товара (может быть числом или undefined).
- `selected: boolean` — статус выбора товара (выбран/не выбран).
- `id: string` — id товара.

### 2. `AppState`
Класс `AppState` предназначен для управления состоянием приложения, связанным с корзиной покупок и процессом оформления заказа. Он наследует от класса `Model<IAppState>` и предоставляет методы и свойства для работы с продуктами, корзиной и формами заказа.

### Свойства
- `basket` — массив объектов `Product`, представляющий текущие товары в корзине.
- `store` — массив объектов `Product`, представляющий доступные товары в магазине.
- `formErrors` — объект, содержащий ошибки валидации формы.
- `order` — объект `IOrder`, содержащий информацию о заказе, включая товары, способ оплаты, общую сумму и контактные данные (адрес, email, телефон).

### Методы
- `addToBasket(value: Product)` — добавляет продукт в корзину.
- `deleteFromBasket(id: string)` — удаляет продукт из корзины по его идентификатору.
- `clearBasket()` — очищает корзину.
- `getBasketAmount()` — возвращает количество товаров в корзине.
- `setItems()` — устанавливает идентификаторы товаров из корзины в объект заказа.
- `validateContacts()` — проверяет корректность контактных данных (email и телефон) и обновляет объект ошибок формы.
- `validateOrder()` — проверяет корректность данных заказа (адрес и способ оплаты) и обновляет объект ошибок формы.
- `setOrderField(field: keyof IOrderForm, value: string | PaymentType)` — устанавливает значение поля в объекте заказа и выполняет валидацию контактных данных и заказа.
- `refreshOrder()` — сбрасывает данные заказа до начального состояния.
- `getTotalBasketPrice()` — возвращает общую стоимость товаров в корзине.
- `setStore(items: IProduct[])` — устанавливает доступные товары в магазине и обновляет состояние.
- `resetSelected()` — сбрасывает выбранные товары в магазине.

## Классы компонентов представления
### 1. `Basket`
`Basket` — это класс, представляющий корзину для покупок, наследующий от класса `Element`. Он управляет отображением элементов корзины и их взаимодействием.

### Свойства
- `_list` — элемент для отображения списка товаров в корзине.
- `_price` — элемент для отображения общей цены товаров.
- `_button` — кнопка для оформления заказа.

### Методы
- `set price(price: number)` — устанавливает текстовое содержимое элемента цены.
- `set list(items: HTMLElement[])` — обновляет список товаров и отключает кнопку, если список пуст.
- `refreshIndices()` — обновляет индексы товаров в списке.

### 2. `StoreItemBasket`

### Свойства
- `_index` — элемент для отображения индекса товара.
- `_title` — элемент для отображения названия товара.
- `_price` — элемент для отображения цены товара.
- `_button` — кнопка для удаления товара из корзины.

### Методы
- `set title(value: string)` — устанавливает название товара.
- `set index(value: number)` — устанавливает индекс товара.
- `set price(value: number)` — устанавливает цену товара.

### 3. `Form<T>`
Класс `Form<T>` представляет собой элемент формы, который наследует от класса `Element<IFormState>`. Он управляет обработкой ввода данных и отправкой формы. В конструкторе инициализируются элементы кнопки отправки и контейнера для ошибок.

### Методы
- `render` — обновляет состояние формы, принимая частичное состояние и передавая его в родительский класс, а также обновляет значения полей ввода.
- `valid` — устанавливает состояние кнопки отправки (активна/неактивна) в зависимости от валидности формы.
- `errors` — устанавливает состояние кнопки отправки (активна/неактивна) в зависимости от валидности формы.

### 4. `Modal`
Класс `Modal` представляет собой модальное окно, наследующее от класса `Element<IModalData>`. Он управляет отображением и закрытием модального окна.

### Методы
- `open` и `close` — отвечают за открытие и закрытие модального окна, соответственно. При открытии добавляется класс для активации стилей, а при закрытии удаляется.
- `render` — вызывает родительский метод для рендеринга данных и открывает модальное окно.

### 5. `Success`
Класс `Success` наследуется от класса `Element<ISuccess>` и представляет собой элемент, отображающий сообщение об успешном заказе.

### Методы
- `set description:` Позволяет устанавливать текстовое содержимое элемента описания.

### 6. `Card`
`Card` — это класс, представляющий карточку товара или элемента, наследующий от базового класса `Element<ICard>`.

### 7. `ItemPreview`
`ItemPreview` — это подкласс `Card`, который расширяет функциональность карточки, добавляя возможность отображения описания товара.

### 8. `Contacts`
`Contacts` — это класс, наследующий от Form<IContacts>, предназначенный для работы с контактной информацией. 

### 9. `Order`
`Order` — это класс, также наследующий от Form<IOrder>, который управляет процессом оформления заказа.

### 10. `Page`
`Page` — это класс, наследующий от Element<IPage>, который управляет основными элементами страницы и взаимодействует с событиями.

### Методы
- `setter counter` — устанавливает текстовое значение для счетчика товаров в корзине.
- `setter store` — заменяет содержимое галереи товарами, переданными в виде массива элементов.
- `setter locked` — блокирует или разблокирует страницу, добавляя или удаляя класс page__wrapper_locked из обертки.
